# 验证说明

## 运行环境

- Windows 11 x64，原版 MSIX Claude Desktop 2.42304.0，包版本 2.42304.0.0。
- 原版内置 Claude Code 2.1.299。
- 实机推理使用 Magpie 0.1.1285 和 `codex/gpt-6.1-sol`。
- 发布工具使用 Node.js 24.13.1；自动测试矩阵覆盖 Node.js 22 的 Windows / Linux。
- 其他 Gateway 的配置合并由测试覆盖，尚未对其他服务做端到端模型推理验收。

## 自动测试与隔离安装验证

20 项测试覆盖：唯一锚点、已安装幂等识别、错误哈希拒绝、路径越界与符号链接拒绝、配置合并、Ultra 能力和策略限制、语言版本拒绝、凭据保留、重复安装保护、升级后拒绝卸载、用户后续设置保留、失败写入撤回及备份损坏拒绝；还包括旧版备份发现、重装新备份、无备份拒绝、未完成事务识别、多备份选择、卸载目标路径与设置键检查。

另在本机隔离目录中使用原版资源副本完成 6 个脚本与 2 个语言文件的真实变换、安装、重复规划和卸载。脚本输出哈希与已实测的客户端补丁一致。原版资源不随测试或安装包分发。

## 0.2.0 双击入口验收

- Windows 原生窗口实际完成普通安装、卸载、含 Ultra 的再次安装与完整卸载。
- 普通安装写入 5 个资源；含 Ultra 安装写入 8 个资源，并合并名称和用户工作流设置。
- 卸载后原设置与测试凭据完整保留，两份历史备份均保留。
- 使用 Windows 自带 .NET Framework 编译器生成两个独立 EXE；运行组件采用官方 Node.js 22.23.3 Windows x64 发行文件并验证固定 SHA256。
- GitHub Windows GUI 构建任务会编译双击包，并运行两个原生入口的启动、运行时校验和参数转义自检。
- 管理员授权窗口及不同账户授权未做本轮交互验收；没有修改真实 WindowsApps 目录权限。资源保护拒绝写入时会停止。
