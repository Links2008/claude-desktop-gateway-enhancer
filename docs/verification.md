# 验证说明

## 运行环境

- Windows 11 x64，原版 MSIX Claude Desktop 2.42304.0，包版本 2.42304.0.0。
- 原版内置 Claude Code 2.1.299。
- 实机推理使用 Magpie 0.1.1285 和 `codex/gpt-6.1-sol`。
- 发布工具使用 Node.js 24.13.1；自动测试矩阵覆盖 Node.js 22 的 Windows / Linux。
- 其他 Gateway 的配置合并由测试覆盖，尚未对其他服务做端到端模型推理验收。

## 自动测试与隔离安装验证

12 项测试覆盖：唯一锚点、已安装幂等识别、错误哈希拒绝、路径越界与符号链接拒绝、配置合并、Ultra 能力和策略限制、语言版本拒绝、凭据保留、重复安装保护、升级后拒绝卸载、用户后续设置保留、失败写入撤回及备份损坏拒绝。

另在本机隔离目录中使用原版资源副本完成 6 个脚本与 2 个语言文件的真实变换、安装、重复规划和卸载。脚本输出哈希与已实测的客户端补丁一致。原版资源不随测试或安装包分发。
